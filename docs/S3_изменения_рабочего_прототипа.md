# S3. Формирование транспортных мест

## Изменения рабочего прототипа

**Статус на 11.10.2026:** 14 из 23 пунктов выполнены; 2 частично готовы; 3 отложены; 4 не начаты.\
**База:** текущий прототип ShipmentBuilder

Отмеченный чекбокс означает полное выполнение пункта. Частично готовые и
отложенные пункты остаются без отметки.

> Модели данных и будущие backend-контракты на данном этапе не
> фиксируются. Изменения описывают UI и поведение прототипа.

## 1. Общий интерфейс

- [x] 1. **Однострочный заголовок страницы**\
    Разместить заголовок «Формирование транспортных мест» в одну строку.

- [x] 2. **Исправить блок ввода / сканирования**\
    Починить сворачивание и разворачивание блока ввода. После
    переключения состояния поле ввода должно корректно отображаться и
    работать.

- [x] 3. **Перенести селекты выбора вида отображения выше**\
    Селекты «Контейнеры / Товары» в левой и правой областях переместить
    выше относительно текущего расположения.

    **Готово:** селекты находятся в строке заголовков; свободное пространство
    отделяет заголовок со счётчиком от селекта и кнопок.

- [x] 4. **Добавить горячие клавиши для основных операций**\
    Предусмотреть hotkeys для операций перемещения, возврата, создания
    ТМ, PAL/MIX, раскрытия ввода и других основных действий. Назначенные сочетания отображать рядом с
    соответствующими кнопками.

    **Готово:** переносы, возвраты, создание и удаление ТМ (Shift+N),
    раскрытие ввода, сброс фильтра и открытие печати. Сочетания вынесены
    в конфиг и показаны на кнопках. PAL/MIX имеют назначения, но остаются
    заглушками. По согласованному решению горячая клавиша истории
    входит в пункт 16 и не блокирует завершение этого пункта.

- [x] 5. **Визуально разделить центральные кнопки**\
    Разделить центральную панель действий на две или три визуальные
    группы: перенос в ТМ, возврат из ТМ, специальные операции PAL/MIX.

## 2. Блок «К распределению»

- [x] 6. **Добавить колонку «ЧЗ»**\
    Показывать значения «Да / Нет» в режимах «Контейнеры» и «Товары».
    Для товара отображать его признак ЧЗ. Для контейнера отображать
    «Да», если хотя бы один товар внутри имеет ЧЗ = «Да».

- [x] 7. **Переименовать «Короба» в «Кол-во мест»**\
    Использовать новое название показателя в таблице.

- [ ] 8. **Добавить ручное изменение «Кол-во мест»** — отложено\
    Значение должно редактироваться пользователем, сохраняться в
    состоянии прототипа и участвовать в пересчёте соответствующих
    итоговых показателей.

    **Решение:** не реализуем на текущем этапе.

## 3. Блок «Транспортные места»

- [ ] 9. **Добавить фильтрацию и переход к содержимому** — частично готово\
    Реализовать поведение, подобное левой части. По нажатию на контейнер
    пользователь должен переходить к просмотру товаров выбранного
    контейнера.

    **Готово:** выбор активного ТМ и просмотр его товаров через селект.
    **Осталось:** автоматический переход к товарам по нажатию на ТМ.

- [ ] 10. **Показывать применённую фильтрацию**\
    Отображать информацию о текущем фильтре аналогично левой части:
    например, выбранный контейнер или другой активный объект фильтрации.

- [x] 11. **Добавить колонку «ЧЗ»**\
    Колонка должна присутствовать в режимах «Контейнеры» и «Товары». Для
    агрегированной сущности отображать «Да», если хотя бы один входящий
    товар имеет ЧЗ = «Да».

- [x] 12. **Добавить колонку SSCC**\
    После получения данных из 1С отображать SSCC рядом с внутренним
    номером ТМ. До получения значения показывать пустое состояние /
    «---».\
    **Готово:** колонка рядом с номером ТМ, пока отображает «---».
    **Решение:** для текущего этапа пункт выполнен. Получение и
    отображение значения из 1С будет реализовано на этапе backend-интеграции.
    **Открытый вопрос:** отображать полный SSCC-код или только факт его
    наличия.

- [x] 13. **Добавить удаление ТМ**\
    Действие «Удалить ТМ» рядом с созданием, сочетание Shift+N.
    После подтверждения товары непустого ТМ возвращаются в
    «К распределению», затем ТМ удаляется. Активным становится предыдущее
    по порядку ТМ; для первого — следующее. Последнее ТМ можно удалить.
    Оставшиеся места не перенумеровываются, удалённые номера в текущем
    сеансе повторно не используются.

- [x] 14. **Переименовать «Короба» в «Кол-во мест»**\
    Использовать новое название показателя в правой таблице.

- [ ] 15. **Поддержать ручное изменение «Кол-во мест»** — отложено\
    Изменение должно сохраняться в состоянии прототипа и отражаться в
    соответствующих агрегатах.

    **Решение:** не реализуем на текущем этапе.

## 4. История действий / лог

- [ ] 16. **Добавить раскрываемую панель истории действий**\
    Панель должна открываться и закрываться кнопкой в интерфейсе и
    горячей клавишей. Назначение добавить в конфиг и показать рядом
    с кнопкой при реализации панели истории.

- [ ] 17. **Отображать историю действий**\
    Для прототипа локально накапливать и показывать основные события:
    создание и удаление ТМ, переносы и возвраты, изменение количества
    мест, действия обмена с 1С и другие значимые операции.

## 5. 1С и верхняя панель

- [x] 18. **Скрыть кнопки «Получить маркировки» и «Получить SSCC»**\
    Убрать эти две отдельные кнопки из текущей верхней панели прототипа.

- [ ] 19. **Добавить / доработать «Печать маркировок 1С»**\
    Предусмотреть отправку на печать PDF-файлов маркировок, полученных
    из 1С. Поддержать печать выбранного ТМ и всех этикеток заказа.

- [ ] 20. **Сохранить существующие варианты печати** — частично готово\
    Новая печать маркировок 1С не должна удалять или заменять
    существующие три варианта печати.

    **Готово:** все три варианта сохранены, можно выбрать несколько.
    **Осталось:** сохранить их при добавлении печати маркировок 1С;
    фактическая печать текущих отчётов пока является заглушкой.

## 6. Попап печати

- [x] 21. **Заменить radio buttons на checkboxes**\
    В попапе выбора отчётов / вариантов печати использовать чекбоксы,
    чтобы пользователь мог выбрать несколько вариантов одновременно.

- [x] 22. **Переименовать «Короба» в «Кол-во мест» во всём интерфейсе**\

    **Решение:** не реализуем на текущем этапе.
