## 1. Состояние фильтра и строки источника

- [ ] 1.1 Добавить взаимоисключающее состояние фильтра контейнера или товара, команды включения/очистки и сброс зависимых выборов.
- [ ] 1.2 Добавить вычисления отфильтрованных строк: товары выбранного контейнера и отдельные строки выбранного товара по контейнерам.
- [ ] 1.3 Реализовать выбор отфильтрованной исходной строки и перенос только её полного текущего остатка в активное ТМ.
- [ ] 1.4 Сохранить текущие операции полного контейнера и агрегированного товара без фильтра, а также неизменность КМ/КА.

## 2. Левая область

- [ ] 2.1 Добавить компактные действия включения фильтра к строкам контейнеров и товаров, не меняя поведение обычного клика по строке.
- [ ] 2.2 Отобразить поля-индикаторы активных фильтров «Контейнер» и «Товар» с очисткой через `×`; не использовать их как селекторы.
- [ ] 2.3 Отрисовать таблицы отфильтрованных строк с контейнером, товаром, количеством и коробами, выбором мышью/клавиатурой и пустыми состояниями.
- [ ] 2.4 Проверить доступность «Переместить строку» и сохранение режима правой области при фильтрованном переносе.

## 3. Проверка

- [ ] 3.1 Проверить взаимное снятие фильтров, сброс выбора и очистку индикатора.
- [ ] 3.2 Проверить перенос только отображаемого остатка товара из выбранного контейнера и отсутствие изменений в других контейнерах.
- [ ] 3.3 Проверить, что перенос без фильтра по-прежнему переносит весь контейнер или агрегированный товар.
- [ ] 3.4 Запустить `npm run lint`, `npm run build` и `openspec validate add-source-filters --strict`.
