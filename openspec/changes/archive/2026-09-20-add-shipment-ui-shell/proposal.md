## Why

Модели, моки и MobX-стор готовы, но приложение показывает только демонстрационную кнопку. Нужен первый экран для оценки компоновки и отображения заказа перед постепенным добавлением действий.

## What Changes

- Заменить стартовый экран каркасом «Формирование транспортных мест».
- Построить страницу на CSS Grid: верх и низ по содержимому, центр занимает оставшуюся высоту окна.
- Показать сводку заказа, прогресс, контейнеры и остатки из существующего MobX-стора.
- Оставить правую область ТМ пустой с понятным сообщением.
- Показать кнопки будущих действий и переключатели отключёнными; сканирование не отображать.
- Сохранить две основные области первого эскиза, применить светлую стилистику с синим акцентом из второго референса.

## Capabilities

### New Capabilities

- `shipment-ui-shell`: каркас страницы формирования ТМ, отображение данных и независимая прокрутка панелей.

### Modified Capabilities

Нет. Предметные правила demo-domain-store и настройки code-quality-tooling сохраняются.

## Impact

App, компоненты новой страницы, подключение mobx-react-lite, стили и необходимые UI-компоненты shadcn/Base UI. Возможны вычисления итогов отдельных контейнеров без новых команд изменения данных. API, сохранение, выбор строк, переносы, КМ/КА, сканирование, обмен и печать не реализуются. Тестовая инфраструктура не добавляется.
