## Зачем

`ShipmentPage` сейчас совмещает композицию страницы с деталями реализации нескольких самостоятельных областей. По мере развития сценария это усложняет понимание владения кодом, импортов и последующих изменений.

## Что изменится

- Страница отгрузки будет разделена на самостоятельно владеемые UI-блоки.
- У каждого блока появится локальный `index.ts`, задающий его явный публичный API.
- Компоненты, хелперы и стили, нужные только блоку, останутся внутри владеющего блока.
- Блоки смогут зависеть только от shared-кода или документированного публичного API другого блока.
- Глобальный shipment-level barrel-файл, реэкспортирующий все блоки, не появится.

## Возможности

### Новые возможности

- `shipment-page-modularity`: Определяет модульное владение и границы импортов в UI страницы отгрузки.

### Изменённые возможности

- Нет.

## Влияние

- Затрагивает `src/pages/shipment/shipment-page.tsx`, связанные UI-модули и стили страницы отгрузки.
- Не изменяет данные домена отгрузки, поведение пользовательского сценария или внешние API.
