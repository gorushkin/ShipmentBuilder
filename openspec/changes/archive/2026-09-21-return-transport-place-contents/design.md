## Context

`ShipmentStore` хранит неизменяемые исходные количества в `SourceLine`, а текущее распределение — в `AllocationLine`. Остатки контейнеров, содержимое ТМ и прогресс вычисляются из этих данных. Правая строка уже выбирает активное ТМ через `activeTransportPlaceId`, но кнопка «Вернуть строку» пока недоступна.

Возврат в этом change означает отмену всех количественных распределений активного ТМ. Постоянное хранение отсутствует, а конкретные КМ/КА ещё не назначаются транспортным местам.

## Goals / Non-Goals

**Goals:**

- разрешить возврат всего содержимого непустого активного ТМ;
- восстановить остатки исходных контейнеров через существующие вычисляемые данные;
- сохранить само ТМ, его активность и распределения других ТМ;
- сбросить выбор исходного контейнера после успешного возврата;
- подключить существующую кнопку без Dialog.

**Non-Goals:**

- возврат отдельного контейнера, товара или количества;
- удаление или перенумерация транспортного места;
- undo и подтверждение операции;
- изменение КМ/КА, REST API и persistence.

## Decisions

### Return removes allocations of the active transport place

Команда возврата проверяет существование активного ТМ и наличие у него хотя бы одной `AllocationLine` с положительным количеством. После успешной проверки она удаляет из `ShipmentData.allocationLines` все строки этого ТМ. `SourceLine` не изменяются, поэтому `remainingLines`, строки контейнеров, итоги и прогресс восстанавливаются существующими вычислениями.

Альтернатива с обнулением количества оставляла бы незначимые строки распределения и усложняла последующие операции. Передача обратных количеств отдельными записями потребовала бы журнал операций, которого в модели прототипа нет.

### The transport place remains active and empty

Возврат не удаляет `TransportPlace` и не меняет `activeTransportPlaceId`. Правая строка остаётся выбранной и показывает нулевые показатели. Это позволяет сразу повторно использовать то же ТМ и не вводит отдельную операцию удаления.

### Source selection is cleared

После успешного возврата `selectedContainerId` сбрасывается. Возврат может изменить состав и остаток нескольких контейнеров, поэтому сохранение прежнего выбора создавало бы риск случайного повторного распределения.

### Only the single-row return action becomes operational

Существующая кнопка «Вернуть строку» становится обычной кнопкой и доступна только для непустого активного ТМ. Нажатие выполняет возврат сразу. «Вернуть всё по фильтру», частичное перемещение и массовое перемещение остаются disabled.

### Marking data remains untouched

Команда изменяет только массив `allocationLines`. `MarkingCode` и `AggregationCode` сохраняются без изменений до отдельного change обработки маркировки.

## Risks / Trade-offs

- [Возврат нельзя отменить отдельной командой] → содержимое можно снова распределить из восстановленных контейнеров; persistence в прототипе отсутствует.
- [Название «Вернуть строку» не описывает объём операции буквально] → сохраняется согласованный текст существующего макета, а область действия определяется выбранной строкой ТМ.
- [Будущие частичные распределения могут связывать одну исходную строку с несколькими ТМ] → удаляются только `AllocationLine` активного ТМ, поэтому распределения остальных ТМ сохраняются.
