## Context

Левая область уже умеет показывать контейнеры или агрегированные остатки по товарам и переносить выбранный контейнер либо весь остаток выбранного товара. Документ процесса задаёт один активный фильтр: контейнер ограничивает список его товарами, а товар раскрывает его остатки по контейнерам. В будущем тот же фильтр будет устанавливаться сканированием; сканирование в этот change не входит.

## Goals / Non-Goals

**Goals:**

- Ввести одно взаимоисключающее состояние фильтра источника.
- Отображать только строки, доступные в контексте фильтра, и переносить только их остаток.
- Дать временное, явное управление фильтрами мышью без смешения его с выбором строки для переноса.

**Non-Goals:**

- Сканирование, скрытое поле ввода, горячие клавиши и автоматический выбор следующей строки.
- Частичные и массовые операции, КМ/КА, изменения правой области, API и persistence.

## Decisions

### Один discriminated filter state

Стор хранит `sourceFilter` со значением `null`, `containerId` или `productId`. Установка одного варианта очищает другой; очистка возвращает обычное отображение. Это напрямую соответствует будущим командам сканера и исключает пересечение фильтров.

### Выбор строки и включение фильтра — разные действия

Клик по строке сохраняет существующее значение выбора для переноса. Отдельная компактная иконка фильтра в строке включает фильтр. Текстовые поля «Контейнер» и «Товар» отображают активный контекст и содержат действие очистки, но не открывают список значений.

Альтернатива — включать фильтр обычным кликом по строке — отвергнута: она лишает пользователя существующей операции переноса всего контейнера или всего товара без фильтра.

### Фильтр меняет гранулярность строк

Без фильтра режим товаров сохраняет агрегированные строки по товару. Фильтр контейнера показывает остатки товаров только выбранного контейнера. Фильтр товара показывает отдельные строки выбранного товара по контейнерам. Обе отфильтрованные формы несут `sourceLineId`, поэтому команда переносит ровно отображаемый остаток строки.

### Операция всегда использует видимую строку

При активном фильтре кнопка «Переместить строку» переносит полный текущий остаток выбранной исходной строки. При отсутствии фильтра сохраняется текущий сценарий: контейнер переносится целиком, а агрегированный товар — из всех контейнеров.

## Risks / Trade-offs

- [Разные гранулярности строк могут запутать действие кнопки] → показывать активный фильтр в панели и очищать выбор при смене/очистке фильтра.
- [Временное управление мышью отличается от сканирования] → оба пути будут вызывать одни и те же методы стора и давать идентичное состояние.
- [Полностью распределённая строка остаётся выбранной] → после успешного переноса и изменения фильтра сбрасывать выбор строки.
