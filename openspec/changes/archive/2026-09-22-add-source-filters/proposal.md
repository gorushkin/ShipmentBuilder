## Why

Оператору нужно ограничивать левую область выбранным контейнером или товаром, чтобы переносить только видимый остаток. Это приближает прототип к будущему сканерному сценарию, не вводя сканирование на данном шаге.

## What Changes

- Добавить взаимоисключающие фильтры источника: по контейнеру и по товару.
- Включать фильтр мышью отдельным действием в строке; текстовые поля «Контейнер» и «Товар» показывают активный фильтр и позволяют его снять, но не являются селекторами.
- При фильтре контейнера показывать только товары этого контейнера; при фильтре товара — строки выбранного товара в контейнерах, где у него есть остаток.
- Сохранить выбор контейнера или товарной строки для переноса и ограничивать «Переместить строку» тем остатком, который отображает активный фильтр.
- Подготовить состояние и команды так, чтобы будущий сканер мог включать те же фильтры без изменения бизнес-правил.

## Capabilities

### New Capabilities

- `source-filters`: Взаимоисключающая фильтрация источника по контейнеру или товару, её отображение и мышиное управление.

### Modified Capabilities

- `product-row-distribution`: Построчный перенос товара учитывает активный фильтр контейнера и переносит только видимый остаток исходной строки.
- `shipment-ui-shell`: Кнопка «Переместить строку» получает контекстное поведение для отфильтрованных строк источника.

## Impact

- Затрагиваются состояние `ShipmentStore`, формирование строк левой области, действия строк и кнопка построчного переноса.
- Сканирование, горячие клавиши, массовые и частичные операции, КМ/КА, API и сохранение состояния не входят в change.
