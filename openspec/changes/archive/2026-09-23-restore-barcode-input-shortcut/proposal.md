## Why

Во время разработки scanner input был временно раскрыт по умолчанию. Из-за
этого штатный сценарий сканирования не соответствует спецификации, а `F2`
визуально не открывает поле. Текст действия возврата также должен описывать
работу с выбранной строкой, а не менять её существующую доменную команду.

## What Changes

- Вернуть скрытое по умолчанию представление scanner input при сохранении его
  enabled, focusable и готовым принимать сканирование.
- Уточнить обработку `F2` и `Esc`: `F2` раскрывает и фокусирует scanner input,
  а `Esc` из раскрытого сфокусированного input возвращает скрытое представление
  без отмены workflow-действия.
- Переименовать действие `Вернуть товар` в `Вернуть строку`, сохранив команду
  `return-product` и её поведение.
