# Design

## Context

DistributionStatus статичен. MobX уже управляет данными и машиной, операции кнопок и сканера сходятся в ScannerWorkflowOrchestrator. Страница занимает высоту viewport и отдает таблицам оставшееся место.

## Goals / Non-Goals

**Goals:** самостоятельное хранилище событий и состояния раскрытия, единая фиксация результатов, сохранение размеров workspace.

**Non-Goals:** backend, localStorage, undo, реализация отключенного обмена с 1С, журнал каждого UI-жеста.

## Decisions

- ActionHistoryStore создается в runtime и внедряется последним параметром конструктора оркестратора; readonly actionHistory открывает его UI. Значение по умолчанию сохраняет существующие тестовые вызовы. В отличие от глобального импорта в оркестраторе это позволяет изолировать экземпляры. Стор не знает о workflow и доменных данных.
- Стор хранит entries, isExpanded; latestEvent и newestFirst вычисляются; append генерирует ID и время, reset очищает историю и закрывает панель. UI отвечает только за DOM, CSS и регистрацию сочетания.
- Результаты записывает оркестратор после mutation; номера и количество фиксируются текстом до удаления. Автосоздание ТМ логируется отдельным событием создания, затем результатом переноса. Существующая защита lastExecutedId предотвращает дубликаты effect. Начальная запись добавляется при успешной загрузке, а при уже имеющемся snapshot — один раз при start.
- Контейнер строки position: relative, список absolute под строкой на всю ее ширину, ограниченная высота и overflow-y: auto. Раскрытие в потоке уменьшило бы таблицы; portal потерял бы связь с блоком. Кнопка использует существующий Button и конфиг historyToggle/F3. Хоткей работает в ручном вводе, соблюдая приостановку диалогами; фокус не меняется.
- Новые события добавляются в начало отображения. Пока панель открыта, положение прокрутки не принудительно меняется; при повторном раскрытии начинается с последних событий.

## Risks / Trade-offs

- Панель перекрывает верх таблиц → ограничить высоту примерно пятью строками и обозначить границы фоном, рамкой и тенью.
- Длинные сообщения меняют высоту → фиксированная высота строки, компактный текст с доступным полным title.
- История растет в рамках сессии → для прототипа без отсечения, перезагрузка и смена заказа очищают записи.
