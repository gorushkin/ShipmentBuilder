# Задачи

## 1. Реестр и разбор нажатий

- [x] 1.1 Создать независимый модуль клавиатурного ввода и нормализацию клавиш с модификаторами; проверить тестами нижний регистр, порядок модификаторов и точное различение Shift, Ctrl, Alt и Meta.
- [x] 1.2 Реализовать регистрацию сочетаний, единственного получателя последовательностей и удаление регистраций; проверить тестами отклонение дубликатов и идемпотентное удаление.
- [x] 1.3 Реализовать распознавание сочетаний с модификаторами и непечатных клавиш с вызовом после последнего отпускания, а также политику редактирования; проверить тестами режимы запрета и разрешения при редактировании, оба порядка отпускания Ctrl+A, несколько модификаторов и левый/правый модификатор.
- [x] 1.4 Добавить единый путь выполнения и обработки синхронных и асинхронных ошибок; проверить тестами, что ошибка не блокирует последующие команды и не создаёт необработанного отклонения.

## 2. Буфер и блокировки

- [x] 2.1 Реализовать буфер с заменяемыми часами и планировщиком, настраиваемой задержкой 200 мс и отложенным одиночным хоткеем, ожидающим и тайм-аут, и отпускание; проверить управляемыми таймерами интервалы ниже, ровно на границе и выше порога.
- [x] 2.2 Реализовать Enter/Tab, Escape и сброс многосимвольной строки без завершителя; проверить тестами исходный регистр, односимвольный штрихкод, отправку только после отпускания завершителя, удержание Enter дольше тайм-аута, однократную отправку и отсутствие вызовов хоткеев символов внутри строки.
- [x] 2.3 Реализовать независимые блокировки `suspend()` и сброс буфера при редактировании, композиции и уходе из окна; проверить тестами вложенность, повторное освобождение и отмену отложенных команд.
- [x] 2.4 Зафиксировать контракт регистрации, правил буфера и освобождения блокировок в документации модуля; проверить соответствие примеров публичному интерфейсу и сценариям спецификации.

## 3. Подключение к странице и ручной ввод

- [x] 3.1 Подключить одну глобальную пару слушателей нажатия и отпускания с очисткой ресурсов и синхронным перехватом принятых событий; проверить интеграционно поглощение повторов принятого нажатия без продления таймера, композицию, прохождение непринятых событий и повторное подключение страницы без дублирования.
- [x] 3.2 Одновременно подключить передачу последовательностей в существующий адаптер и заменить скрытый инпут условно монтируемой формой; убрать возврат и удержание фокуса, передать раскрытие внешнему контроллеру. Проверить в браузере сканирование с Enter/Tab при отсутствии поля в DOM, ручную отправку и сохранение текста при сворачивании.
- [x] 3.3 Перенести текущие F2/Esc и отмену страницы на общий реестр без нового назначения сочетаний; проверить переключение кнопкой и клавишами, защиту другого поля ввода и отсутствие двойной отмены при непустом буфере.
- [x] 3.4 Подключить независимые блокировки к диалогам, меню и выпадающим спискам страницы на весь срок открытия; проверить в браузере клавиатурную работу элементов, вложенные блокировки, закрытие и размонтирование без утечек.
- [x] 3.5 Проверить передачу последовательностей во время асинхронного перемещения без очереди менеджера и изменения правил предметной области; интеграционный тест должен подтвердить вызов существующего получателя и независимую обработку следующей строки.

## 4. Общая проверка

- [x] 4.1 Выполнить `npm run test`, `npm run build`, `npm run lint` и проверку форматирования затронутых файлов; устранить вызванные изменением ошибки.
- [x] 4.2 Проверить сквозной сценарий в браузере: сканирование без ручного поля, раскрытие и сворачивание, ввод количества, открытие списка и диалога, возврат в окно и следующий скан. Подтвердить отсутствие кражи фокуса и двойной отправки.
