# Design

## Context

См. proposal.md для мотивации. DestinationPanel хранит режим локально, DestinationTransportPlaceTable напрямую выбирает ТМ через orchestrator. Проекция товаров уже ограничена activeTransportPlaceId. Это ТМ одновременно является целью переноса и контекстом возврата; сброс просмотра не должен очищать его. Существующая спецификация запрещает автоматическую смену режима, поэтому её поведение изменяется явно.

## Goals / Non-Goals

**Goals:** согласовать режим, индикатор и фактически отображаемые товары; сохранить существующие ограничения выбора во время операций.

**Non-Goals:** общий компонент таблиц, новый доменный фильтр, товары всех ТМ в одной проекции, изменения сканирования и контрактов backend.

## Decisions

### Режим просмотра отделён от активного места

Хранить режим в DestinationPanel; в режиме товаров активное ТМ определяет фильтр и подпись. Сброс меняет только режим на список ТМ. Отдельный destinationFilterId не нужен: он дублировал бы activeTransportPlaceId и мог рассинхронизировать возврат и показанные товары. Альтернатива со снятием active ТМ отвергнута согласованным поведением сброса.

### Переход после принятого выбора

Передать таблице ТМ обработчик выбора из панели по образцу SourceContainerTable. Обработчик вызывает workflow selection и переключает режим только при принятом выборе. При необходимости orchestrator возвращает явный результат принятия выбора; нельзя определять успех только по совпадению active ID, поскольку повторный выбор уже активного ТМ также может быть отклонён. Сохранить Click/Enter/Space и существующие ограничения machine.

Альтернатива — переключать режим при любом изменении active ID — неверна: создание и сканирование в режиме списка не должны неожиданно открывать товары.

### Индикатор следует отображаемой проекции

В режиме товаров показывать номер текущего active ТМ и локальную кнопку «Сбросить» с Shift+X, используя оформление индикатора слева. Назначение clearDestinationFilter хранится в конфиге команд; X сохраняется для левой стороны. Ручной переход в список скрывает индикатор. При смене active ТМ в режиме товаров проекция и подпись следуют новому месту; при исчезновении всех мест режим возвращается к списку. Пустое существующее ТМ сохраняет индикатор.

## Risks / Trade-offs

- Отклонённый выбор может открыть неверный контекст → переключать режим только после принятого workflow action; проверить ограничения ожидания количества и переноса.
- Удаление или создание ТМ может оставить устаревшую подпись → получать номер из текущего active ТМ, проверить жизненный цикл и последнее удаление.
- Сброс может случайно изменить цель переноса или левый фильтр → действие сброса меняет только состояние просмотра; проверять последующий перенос.

## Migration Plan

Изменение локального UI не требует миграций данных. После реализации и проверки обновить пункты 9 и 10 и итоговый статус документа S3. Откат возвращает прежнюю панель и требования без преобразования данных.
