# Verification

## Автоматические проверки

- `npm test`: 16 файлов, 120 тестов успешно.
- `npm run lint`: успешно, без предупреждений после локального исправления порядка ключей.
- `npm run build`: успешно; существующие предупреждения Vite о конфигурации и размере bundle.
- `npm run format:check`: существующие ошибки в неизменённых `src/components/ui/radio-group.tsx` и `src/features/scanner-workflow/demo-shipment-snapshot-loader.ts`. Изменённые файлы отформатированы и отдельно проверены.
- `openspec validate align-visible-barcodes-and-scan-filters --strict`: успешно.
- `git diff --check`: успешно.

Тестами проверены публичные коды всех сущностей обычного и большого snapshot,
созданные ТМ, уникальность после нормализации, команды, неизвестные коды и коллизии.
Проверены переключение контейнерного фильтра на товар без переноса и со сбросом pin,
товар из другого контейнера, нулевой остаток, повторные переносы, явный возврат,
ограничения количества и busy. Правый просмотр получает новый revision при каждом
принятом скане ТМ, включая уже активное; отклонённые сканы revision не меняют.

## Браузер

Chrome / Playwright, 1280×720 и 1440×900. Оба сценария прошли без ошибок браузера:

1. Раскрыт ввод F2-кнопкой, введён ` n00001 `: слева контейнер N00001.
2. Введён `10001`: фильтр товара по всему заказу, видны две исходные строки,
   распределено 0 из 44 шт.
3. Введён `тм-001`: открыты товары ТМ справа, левый фильтр сохранён.
4. Правый просмотр сброшен; повторный `ТМ-001` снова открывает состав того же места.
5. Два последующих `10001` переносят 10 и 15 шт., справа виден товар выбранного ТМ.
6. После выбора другого контейнера скан полностью распределённого `10001` сохраняет
   пустой фильтр слева и сообщает «Весь товар уже распределён», без возврата.
7. Создано ТМ-002, его видимый код введён вручную: справа выбранное пустое место.

Снимки результата: `screenshots/visible-scans-1280.png` и `screenshots/visible-scans-1440.png`.

## Границы изменения

Внутренние ID и связи данных сохранены. Мышь и явные команды сохраняют операции
с товаром внутри контейнера. КМ/КА, заказ, SSCC и реальные форматы не добавлялись.
`ТМ-001` использует кириллические Т/М; латинское TM1 больше не является mock-алиасом.
