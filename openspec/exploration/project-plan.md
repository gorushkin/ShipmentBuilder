# План прототипа Shipment Builder

## Цель

Собрать демонстрационный интерфейс формирования транспортных мест на локальных моках. Состояние живёт только в текущем сеансе; REST API, persistence и сканирование появятся позже.

## Техническая основа

- React, TypeScript и Vite;
- MobX и один `ShipmentStore`;
- Tailwind CSS и shadcn/ui на Base UI;
- CSS Grid для каркаса страницы;
- локальные данные без backend и browser storage.

## Готово

- [x] Модели заказа, товаров, контейнеров отбора, ТМ, распределений, КМ и КА.
- [x] Демонстрационные данные и вычисляемые итоги заказа, остатка и прогресса.
- [x] Каркас страницы с независимыми прокручиваемыми панелями.
- [x] Компоненты shadcn/ui и базовая визуальная система.
- [x] Локальное создание и выбор активного ТМ.

- [x] Возврат всего содержимого активного ТМ.

## Ближайший шаг

### Режим «Товары» в левой области

- [ ] Активировать переключатель «Контейнеры / Товары».
- [ ] По умолчанию показывать контейнеры.
- [ ] В режиме «Товары» показывать общий список остатка заказа, сгруппированный по товару.
- [ ] Использовать столбцы: код товара, наименование, штуки, короба, контейнеры.
- [ ] Скрывать товары с нулевым остатком.
- [ ] Добавить выбор товарной строки мышью и клавиатурой.
- [ ] Сбрасывать выбор строки при смене режима.
- [ ] Оставить перенос товарной строки и фильтры недоступными.

## Текущие ограничения прототипа

- Один пользователь работает с одним заказом.
- Ограничения вместимости транспортного места не моделируются.
- Изменения не сохраняются после перезагрузки.
- КМ и КА присутствуют в данных, но не участвуют в операциях.
- Автоматические тесты пока не добавляются; проверка выполняется через lint, production build и браузерные сценарии.
