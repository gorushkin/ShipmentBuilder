# Barcode Input

## Purpose

Определяет постоянно доступную точку ввода штрихкода, соединённую с
сценарной машиной без прямых доменных операций.

## Requirements

### Requirement: Persistent barcode entry point

Панель `BarcodeInput` SHALL располагаться перед сведениями о заказе. Раскрытием SHALL управлять внешний контроллер через кнопку и глобальный обработчик; поле SHALL NOT иметь слушателей раскрытия. Доступно именованное ручное поле SHALL монтироваться при раскрытии и удаляться при сворачивании. Вне редактируемых полей глобальный обработчик SHALL передавать завершённые последовательности входному адаптеру без скрытого инпута.

#### Scenario: Hidden scanner input accepts a scan
- **WHEN** ручное поле свёрнуто и сканер вводит последовательность с завершающим Enter или Tab вне редактируемых областей и без блокировки слушателя
- **THEN** поле отсутствует в DOM, а завершённая строка передаётся входному адаптеру один раз

#### Scenario: Сохранение ручного текста
- **WHEN** пользователь вводит текст, сворачивает и снова раскрывает ручной ввод
- **THEN** поле вновь смонтировано с ранее введённым текстом

### Requirement: Technical submit before workflow integration

Нативный submit `BarcodeInput` по `Enter` SHALL очищать input и передавать
каждое непустое значение во входной adapter. Adapter SHALL отвечать за
нормализацию, resolver и передачу typed event в `ScanMachine`. Submit SHALL NOT
писать технический console log и SHALL NOT напрямую изменять данные заказа,
фильтры, транспортные места или распределения.

#### Scenario: Submit a manually entered barcode

- **WHEN** пользователь вводит `  P1  ` и нажимает `Enter`
- **THEN** input очищен и adapter получает введённое непустое значение
- **AND** data store не изменяется напрямую из `BarcodeInput`

#### Scenario: Submit an empty barcode

- **WHEN** пользователь отправляет поле, содержащее только пробелы
- **THEN** компонент очищает поле и не вызывает input adapter

### Requirement: Scanner focus and manual-entry presentation

Панель SHALL предоставлять кнопку переключения ручного ввода и сохранять текущее переключение по F2 и сворачивание по Esc через единый механизм клавиатуры. При раскрытии поле SHALL однократно получать фокус. Постоянный возврат фокуса и его удержание при кликах SHALL отсутствовать. Сворачивание SHALL NOT отменять рабочее действие. Отдельной кнопки отправки SHALL NOT быть. Во время перемещения ручное поле SHALL быть отключено, а панель SHALL отображать состояние обработки.

#### Scenario: Reveal and hide manual entry
- **WHEN** пользователь раскрывает ввод кнопкой или F2, пока нет диалога и фокуса в другом поле
- **THEN** поле монтируется и однократно получает фокус
- **WHEN** пользователь сворачивает его кнопкой, повторным F2 либо Esc в поле штрихкода
- **THEN** поле удаляется, рабочее действие не отменяется и постоянного возврата фокуса нет

#### Scenario: Partial-quantity dialog keeps focus
- **WHEN** открыт диалог частичного перемещения количества
- **THEN** поле штрихкода не перехватывает фокус у поля количества, а глобальный слушатель приостановлен

#### Scenario: Display pending transfer processing
- **WHEN** машина находится в состоянии перемещения контейнера
- **THEN** раскрытое ручное поле отключено, а панель показывает состояние обработки
- **AND** глобальный приём последовательностей не отключается только из-за перемещения

#### Scenario: Клик вне поля
- **WHEN** пользователь нажимает другой доступный элемент интерфейса после раскрытия ручного ввода
- **THEN** фокус переходит согласно штатному поведению элемента и не возвращается автоматически в поле штрихкода

### Requirement: Prominent action-panel presentation

`BarcodeInput` SHALL отображать полученный статус workflow в своей статусной
области как панель действий перед сведениями о заказе. Область текста SHALL
занимать доступное свободное пространство, использовать увеличенный относительно
остальных controls читаемый текст и переносить длинную подсказку, не скрывая
ручной input или кнопку раскрытия.

#### Scenario: Long action text fits the scanner row

- **WHEN** панель показывает длинную подсказку на доступной desktop-ширине
- **THEN** текст остаётся читаемым в границах `BarcodeInput`, а input и кнопка
  «Развернуть ввод» остаются доступны
