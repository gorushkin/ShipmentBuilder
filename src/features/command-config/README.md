# Настройки команд

Редактируйте `public/commands.yaml` в разработке или `commands.yaml` рядом с
`index.html` в опубликованном приложении. Vite копирует файл в `dist`.
Приложение загружает его перед первым рендером без HTTP-кеширования.
После изменения файла обновите страницу; пересборка опубликованного приложения
не требуется. Настройки общие для пользователей этого экземпляра приложения.

```yaml
commands:
  printReports:
    # Открыть диалог отчётов
    label: Печать
    description: Открыть выбор отчета для печати
    shortcut: ctrl+p
  transferRow:
    shortcut: null # Отключить сочетание, сохранив кнопку
```

ID команды связывает настройку с обработчиком в приложении. Название,
описание и сочетание используются кнопками, `title`, доступным описанием и
регистрацией клавиатурного обработчика. Доступность и сами действия остаются
в коде. Кнопки внутри диалогов не входят в этот файл.

Можно переопределять отдельные поля и команды: отсутствующие значения берутся
из `defaults.ts`. Буквы сопоставляются по символу текущей раскладки. Модификаторы:
`ctrl`, `alt`, `shift`, `meta`; примеры: `shift+d`, `F2`, `Escape`.
Все непустые сочетания должны быть уникальны, включая будущие disabled-действия.

Неизвестные команды/поля, пустые подписи, неправильные сочетания и конфликты
отклоняют весь файл. При ошибке загрузки или проверки приложение использует
встроенные настройки и пишет причину в консоль. Загрузка ограничена 5 секундами.
Сочетания браузера могут перехватываться браузером. Escape продолжает иметь
особую роль очистки буфера сканирования независимо от назначения команды cancel.
